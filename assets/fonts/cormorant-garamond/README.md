# Cormorant Garamond

Self-hosted Cormorant Garamond Medium (500), Google Fonts v21. Unmodified WOFF2
subsets cover Turkish (Latin + Latin Extended) and Russian (Cyrillic). Total:
56,432 bytes. OFL.txt contains the SIL Open Font License and copyright notices.

These fonts are used only for Valeria's headings and names at weight 500.
A subtle vertical gold gradient is clipped to the text, with a solid-color
fallback. Print and forced-colors modes use solid system text for legibility.
The course is scoped by the resolved course ID `course_1781255103582`, including
short `?c=` URLs.
Body text, buttons, form fields and all other courses keep their original fonts.
Font files are served by the application, with `font-display: swap` and a system
serif fallback; no font service is contacted at runtime.

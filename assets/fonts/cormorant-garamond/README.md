# Cormorant Garamond

Self-hosted Cormorant Garamond Regular (400), Google Fonts v21. Unmodified WOFF2
subsets cover Turkish (Latin + Latin Extended) and Russian (Cyrillic). Total:
55,540 bytes. OFL.txt contains the SIL Open Font License and copyright notices.

These fonts are used only for Valeria's headings and names. The course is scoped
by the resolved course ID `course_1781255103582`, including short `?c=` URLs.
Body text, buttons, form fields and all other courses keep their original fonts.
Font files are served by the application, with `font-display: swap` and a system
serif fallback; no font service is contacted at runtime.

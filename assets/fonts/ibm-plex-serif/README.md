# IBM Plex Serif

Self-hosted IBM Plex Serif SemiBold (600), Google Fonts v20. Unmodified WOFF2
subsets support Turkish (Latin + Latin Extended) and Russian (Cyrillic).
Total size: 48,272 bytes. OFL.txt includes the SIL Open Font License and notices.

Only Valeria's headings and names use this font, scoped to the resolved course ID
`course_1781255103582`. Body text, controls and other courses retain their existing
fonts. The text has a subtle gold gradient with a solid-color fallback; print and
forced-colors modes use solid system text. Files load from the application's own
origin, with font-display: swap and a system-serif fallback.
